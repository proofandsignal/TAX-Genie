# TAX-GENIE BUILD-001 to product

## Market gate (research → validation)
EU cross-border B2B VAT as pilot. Select a single home/expense country pair after consulting a tax specialist; deadlines, expense exclusions and documentation requirements vary. Do not assume that detected VAT is recoverable.

## Backlog and acceptance
- [x] Repository isolation and public-data policy.
- [x] Intake triage with explicit non-eligibility status.
- [x] Synthetic unit tests.
- [ ] Country-pair rule matrix with primary official sources, review date and owner.
- [ ] Partner interviews (5+) and 50 public-signal leads verified for legal outreach.
- [ ] Secure private file intake + authentication, retention and deletion.
- [ ] Extraction evaluation on 50 consented/anonymized cases.
- [ ] Human legal and tax approval for report language.
- [ ] Opt-in B2B pilot and paid conversion measurement.
- [ ] Deploy with security checks, observability and incident response.

## Metrics
Precision of opportunity candidates, false-positive rate, evidence completeness, verified refund amount vs identified amount, processing cost/case, reviewer minutes, lead-to-paid conversion, chargebacks.

## Release gate
No marketing claims of eligibility, jurisdictional coverage, automatically filed claims or guaranteed refund without supporting evidence and review.
